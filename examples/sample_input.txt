The Harbor Operations Hub coordinates maintenance work for the North Pier. The hub, which operators also call the harbor hub, receives inspection packages from the Asset Catalog and sends approved work orders to the Scheduling Service. The Asset Catalog stores an entry for every physical pump, crane, and sensor. An Asset Catalog Record is the database record that describes an asset; it is not the physical asset itself. When an inspector mentions “HARBOR HUB” in a field note, the phrase refers to the Harbor Operations Hub. The Maintenance Team owns the hub, while the Port Engineering Group owns the Asset Catalog. The hub records every transfer so that supervisors can trace which inspection package produced a work order.

Inspection Policy 4.2 applies from 1 September 2026 until 31 March 2027. During that period, the Condition Review checks each inspection package against the corresponding Asset Catalog Record. The review verifies that the record names the inspected asset, contains a current safety classification, and cites the calibration certificate used by the inspector. If all required fields are present, the Condition Review allows the Scheduling Service to create a work slot. If a safety classification is missing, the Condition Review blocks scheduling and sends a correction notice to the Maintenance Team. The inspection package is the object evaluated by the review; the package does not itself allow or block scheduling. Policy 4.1 remains available for historical queries but does not govern new work orders after 1 September 2026.

The Scheduling Service creates a Maintenance Work Order only after the Condition Review has allowed scheduling. Each Maintenance Work Order references exactly one Asset Catalog Record and identifies the physical asset that technicians will service. The service then sends the order to the Crew Planner, and the Crew Planner assigns a qualified technician. A Maintenance Work Order must never be merged with the pump, crane, or sensor described by its referenced record. Similarly, an Asset Catalog Record is evidence about an asset rather than an alias for the asset. If the Crew Planner cannot find a qualified technician before the planned start time, the Staffing Rule prevents dispatch. That prevention is a positive action of the Staffing Rule and is not a denial of the relation. The rule also creates a staffing alert for the Maintenance Team.

Version 3.7 of the Sensor Gateway publishes vibration readings every five minutes. The gateway sends each reading to the Harbor Operations Hub, and the hub associates the reading with the Asset Catalog Record for the monitored sensor. A high vibration reading causes the Risk Evaluator to create a Priority Review. The Priority Review may delay an existing Maintenance Work Order when the reading exceeds the limit specified by Inspection Policy 4.2. Before version 3.7, Sensor Gateway version 3.6 published readings every fifteen minutes and did not attach the calibration identifier. The Calibration Control rejects a reading only when its calibration identifier is absent or expired. A rejected reading remains stored for audit, but it cannot satisfy the evidence requirement for a Priority Review.

At the end of each shift, the Harbor Operations Hub sends completed work results to the Operations Ledger. The Operations Ledger stores the completion time, technician identity, work-order identifier, and final asset condition. The Quality Monitor measures the number of completed orders and delayed orders each day. Monitoring reports performance but does not validate inspection packages, authorize work, or replace the Condition Review. Every Monday, the Maintenance Team reviews the measurements with the Port Engineering Group. If delayed orders exceed ten percent during the previous seven days, the Capacity Plan requires the Crew Planner to reserve an additional technician for the next week. Reserving capacity reduces the expected scheduling delay, and the reduced delay enables the Maintenance Team to complete urgent repairs sooner.

The Audit Portal reads decisions from the Operations Ledger and displays the evidence that supported each decision. Supervisors can follow a work order back to its inspection package, Asset Catalog Record, policy version, and calibration certificate. The portal displays the Harbor Operations Hub as “harbor hub” in compact views, but both names denote the same component. The Audit Portal does not alter records and does not decide whether work may proceed. When an operator corrects an Asset Catalog Record, the Asset Catalog preserves the earlier revision and records the time of the correction. A corrected record can support a new Condition Review, but it does not retroactively change a review that was completed with the earlier revision.
