# Fact-Graph Checklist

- Distinguish concepts, records, versions, controls, and outcomes.
- Require explicit evidence for aliases and equivalence.
- Verify source and target roles, negation, modality, conditions, quantities, versions, and time.
- Reject unresolved local IDs and dangling endpoints.
- Preserve extracted `raw_relation`; keep `FACT_RELATION` as the Neo4j type.
- Treat JSON as authoritative and Neo4j as an exact projection.
