# Golden Review Checklist

- Use a clean output location and unchanged input fixture.
- Compare units, entities, relations, qualifiers, evidence, IDs, and call counts.
- Review false merges, missed aliases, wrong endpoints, polarity, versions, time, and isolated evidence-backed nodes.
- Separate runtime defects from model extraction errors.
- Require zero post-extraction semantic calls and exact JSON/Neo4j parity.
- Keep generated outputs and local reports ignored.
