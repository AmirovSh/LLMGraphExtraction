# Text Logic Checklist

- Enumerate regexes, replacement tables, keyword maps, tokenizers, and normalizers.
- Determine whether each operation changes representation or infers meaning.
- Verify sentence splitting does not divide decimals or version identifiers.
- Verify normalization cannot collapse distinct entity names or relations.
- Preserve offsets and exact evidence text through every deterministic stage.
- Require semantic work to remain in the approved extraction contract, not preprocessing.
