## 0.1.0-rc1 - Unreleased

Experimental release candidate for controlled evaluation:

- one schema-constrained Kimi K2.6 extraction request per deterministic evidence span;
- typed schema, evidence, temporal, and final-graph validation;
- observable `bge-m3` entity resolution with authoritative JSON output;
- ownership-bound transactional Neo4j projection and exact parity checks;
- truthful terminal attempt accounting and offline public regression gates;
- sanitized source identity, restricted request overrides, and explicit no-resume behavior.

Semantic extraction remains probabilistic. This release is not positioned as production-ready.
