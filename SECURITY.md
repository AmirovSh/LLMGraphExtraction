# Security Policy

## Supported status

This project is an experimental release candidate intended for controlled local evaluation. It does not currently promise production security support or a fixed vulnerability-support lifetime.

## Reporting a vulnerability

After publication, use the repository's private GitHub security reporting feature if the owner enables it. Until a private channel is published, contact the repository owner through an already established private channel.

Do not open a public issue containing credentials, private endpoints, source documents, raw model responses, or exploit details that expose sensitive data. If no private reporting route is available, disclose only that a private contact channel is needed.

## Sensitive run artifacts

Run directories may retain source text, model requests and responses, and derived graph data. Operators are responsible for access control, document classification, retention, backups, and secure deletion.
